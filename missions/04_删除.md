# M04 删除重构（约 35 分钟）

## 为什么做这个

你 1.2 的删除**功能是对的，但结构很脆**：为了拿一个名字遍历了两遍，`delete_choice` 只在循环里被赋值，`Y` 大写不认，用户按 `n` 时静默退出、以为删了。
这一关把"能跑"变成"改得动"：抽一个查找函数出来，后面查询、修改都要用它。

## 接口契约

| 项 | 要求 |
|---|---|
| 菜单 | `2` 进入删除 |
| 确认 | 输入 `y` 或 `Y` 才删；其他任何输入都视为取消 |
| 取消 | 数据不变（提示语自己定） |
| 找不到 | `未找到该学号学生` |
| 删除后 | 其余学生的顺序、学号、分数都不受影响 |

## 动手步骤

1. **先抽函数**：`find_student(student_id)`，找到返回那个学生字典，找不到返回 `None`。
2. **改成一遍**：调一次 `find_student` → 判断 `None` → 确认 → 删。
3. 删除用 `students.remove(target)`。
   注意：这是**原地修改**，所以不需要 `global students`；你原来写 `students = [...]` 是重新绑定，才必须 `global`。
4. 确认那里做两件事：`strip()` 去掉空格、`lower()` 兼容大小写。
5. 跑测试；再手工删中间一个，确认前后两个都还在。
