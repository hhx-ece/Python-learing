# M01 输入契约（约 40 分钟）

## 为什么先做这个

你现在能存进 `-5` 分、`9999` 分、空名字。这些脏数据一旦进了列表，后面的统计、查询、导出全部不可信——**校验是所有功能的入口**。
这一关顺手把菜单和列表格式统一，因为它们会出现在后面每一关里。

## 接口契约

| 项 | 要求 |
|---|---|
| 菜单 | `1 添加 / 2 删除 / 3 查看 / 4 查询 / 5 修改 / 6 统计 / 0 退出`（4/5/6 现在可以先占位） |
| 退出 | **按 0 退出**（你原来是 4，测试靠 0 结束） |
| 分数 | 只接受 `0 ~ 100` 的整数，越界重问，不能存进去 |
| 名字 | 去掉首尾空格后不能为空，空的重问 |
| 列表 | 每个学生**一行**：`学号 姓名 成绩`，列间空格，不加冒号 |
| 添加成功 | 仍然打印 `该学生的学号为:1001`（沿用 1.2 的格式） |

## 动手步骤

1. **先改菜单**。把退出改成 0，加上 4/5/6 三个占位（先打印"功能开发中"也行）。
   改完先跑一次测试：这时失败信息会从"输入用完了"变成"找不到这一行"——说明流程通了，只是格式不对。
2. **加 `get_name()`**：`while True` 里读名字，`strip()` 后为空就重问。
3. **给 `get_int()` 加两个可选参数 `low` / `high`**，越界就打印一句提示再重问。
   分数那次调用改成 `get_int("请输入学生的分数:", 0, 100)`。
4. **把 `show_students()` 改成表格**。先别管中英文对齐，能用空格分开就行；想让表格不歪，再去看 `提示.md` 第 1 节。
5. 跑测试，全绿为止。
