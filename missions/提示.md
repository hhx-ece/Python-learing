## 第 1 节 · M01 输入契约

**提示 1 —— 先改菜单，别急着改校验。**
把退出改成 `0` 之后重跑测试，失败信息会从「输入用完了」变成「找不到这一行：1001 张三 90」。
这说明流程已经通了，问题只剩格式。**先让程序跑到底，再修细节**，否则你分不清是流程错还是格式错。

**提示 2 —— `get_int` 的骨架长这样：**

```python
def get_int(prompt, low=None, high=None):
    while True:
        try:
            num = int(input(prompt))
        except ValueError:
            print("...")
            continue          # 回到 while 开头重问
        if low is not None and num < low:
            print("...")
            continue
        if high is not None and num > high:
            print("...")
            continue
        return num
```

`continue` 是这里的灵魂：错误分支永远不 `return`，只有全部通过才返回值。

**提示 3 —— 表格对齐。**
`f"{'张三':<8}"` 对中文没用，因为中文字符在终端占 **2 格**，而 Python 按 1 个字符算。
两个办法：`unicodedata.east_asian_width(ch) in "WF"` 自己算宽度；或者先用制表符 `\t` 糊过去，等 M05 之后再美化。

## 第 2 节 · M02 查询

**提示 1 —— 先把打印变成"接受参数"的函数。**
现在 `show_students()` 直接读全局 `students`。把它改成 `print_list(records)`，`show_students()` 只留 `print_list(students)`。
这样查询结果 `print_list(结果)` 就能复用同一套表格。

**提示 2 —— 筛选条件。**
一行就够：

```python
result = [s for s in students if 关键字 in s["name"] or 关键字 == str(s["id"])]
```

注意 `s["id"]` 是整数，关键字是字符串，必须 `str()` 一下。

**提示 3 —— 空关键字。**
先 `strip()`，再判断 `if not keyword: print(...); return`。
不处理的话，空字符串 `"" in "张三"` 永远为真，你会把所有人列出来——这不算崩溃，但算 bug。

## 第 3 节 · M03 修改

**提示 1 —— 顺序错了会脏数据。**
先读名字、读分数，**都拿到之后再决定改不改**。不要在读到名字时就写进 `target["name"]`。

**提示 2 —— 用 `None` 表示"这一项不改"。**

```python
new_score = None
if raw.strip():
    ...
    new_score = int(raw)
```

空字符串是 `""`，`0` 也是"假"，所以判断"有没有输入"要用 `if raw.strip():`，不要用 `if raw:` 之后再和 `0` 混在一起。

**提示 3 —— 学号不存在时别继续问名字。**
先 `find_student`，`is None` 就 `return`，否则用户会被问两个问题再被告知"没这个人"。

## 第 4 节 · M04 删除

**提示 1 —— 一个函数替掉两遍遍历。**
`find_student()` 返回字典或 `None`。找到之后你手里就有名字、有分数，不用再遍历第二次。

**提示 2 —— `remove` 和 `global` 的关系。**
`students.remove(target)` 改的是列表**内部**，绑定没变，所以不需要 `global`。
`students = [...]` 是让名字指向一个新列表，属于重新绑定，才需要 `global`。
想清楚这个区别，M06 和以后学类都用得上。

**提示 3 —— 大小写。**
`answer.strip().lower() != "y"` 一行同时处理空格和大小写。

## 第 5 节 · M05 统计

**提示 1 —— 格式化。**
`f"{平均分:.1f}"` 保留一位小数；`f"{及格率:.1f}%"`。
契约里的冒号是**半角** `:`，别打成全角 `：`，否则测试匹配不上（这是真实的踩坑点）。

**提示 2 —— 最高分可以直接拿对象。**

```python
best = max(students, key=lambda s: s["score"])
```

如果只要分数不要人，`max(scores)` 就够。

**提示 3 —— 先处理空库。**
`sum([]) / len([])` 会 `ZeroDivisionError`。空库要在最前面 `return`。

## 第 6 节 · M06 持久化

**提示 1 —— 路径。**
`Path(__file__).resolve().with_name("students.json")`：跟着脚本走，双击运行也不会存错地方。
`Path("students.json")` 是跟着"当前工作目录"走，换个地方启动就找不到数据了。

**提示 2 —— 存什么。**
至少要存两样：`students` 列表、`next_id`。
只存 `students` 的话，重启后 `next_id` 从 1001 重新开始，就会发出重复学号——测试里专门有一条抓这个。

**提示 3 —— 顺序。**
```
改内存 → 更新计数器 → 保存
```
不是"保存 → 更新计数器"。文件里的计数器必须是**下一个要用的号**，不是"最后用过的号"。
另外，保存时用临时文件 + `os.replace`，别直接覆盖。
