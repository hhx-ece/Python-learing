# M05 统计（约 35 分钟）

## 为什么做这个

统计是「把数据变成信息」。这一关练三样很常用的东西：常量、列表推导式、`max(key=...)`。
另外它会暴露一个设计问题：及格线如果写死在三个地方，改一次就要改三处。

## 接口契约

输出**必须**是这五行（冒号是半角，数字格式照抄）：

```
人数:2
平均分:72.5
最高分:90
最低分:55
及格率:50.0%
```

| 项 | 要求 |
|---|---|
| 菜单 | `6` 进入统计 |
| 平均分 | 保留 1 位小数 |
| 及格率 | 保留 1 位小数 + `%` |
| 及格线 | 用常量 `PASS_LINE = 60`（"状态"列也用它） |
| 空库 | `系统中暂无学生成绩` |

## 动手步骤

1. 定义 `PASS_LINE = 60`，把「查看」里的 `>= 60` 也换成它。
2. 空库先返回。
3. 算：人数 `len`、平均分 `sum/len`、最高最低 `max/min`、及格率 `len(passed)/len * 100`。
4. 用 f-string 的格式符控制小数位（`:.1f`）。
5. 跑测试；然后**手工**把 `PASS_LINE` 改成 70，再跑一次统计和查看，看「状态」和「及格率」是不是同时变了。
