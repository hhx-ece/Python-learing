# M02 查询（约 40 分钟）

## 为什么做这个

查询是「复用」的第一课：打印逻辑只该写一遍，查询和查看共用它。
做完你会发现，函数不是"把代码装起来"，而是**让别人能拿你的结果继续干活**。

## 接口契约

| 项 | 要求 |
|---|---|
| 菜单 | `4` 进入查询 |
| 匹配规则 | 学号**精确**相等；姓名**包含**关键字即匹配 |
| 输出 | 和「查看」同一种表格（一行一个学生），每行带分数 |
| 查不到 | 打印 `没有找到符合条件的学生` |
| 空关键字 | 直接回车时，给一句提示后返回菜单（别崩、别把所有人列出来） |

## 动手步骤

1. 先问自己：现在的 `show_students()` 如果把「要打印的列表」当成参数，会变成什么样？
   把它改成 `print_list(records)`，`show_students()` 只剩一行调用。
2. 写 `search_student()`：
   - 读关键字（记得 `strip()`）
   - 空关键字 → 提示 → `return`
   - 用列表推导式筛，条件：`关键字 in 姓名 or 关键字 == str(学号)`
   - 空结果 → 契约里那句话
   - 有结果 → 交给 `print_list`
3. 菜单加 `4`，跑测试。
